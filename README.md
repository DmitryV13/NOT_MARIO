# NOT_MARIO

## Build

Requirements: Windows, Visual Studio 2022+ (Desktop development with C++), PowerShell, internet on the first build.

1. Clone the repository.
2. Open the `.sln` in Visual Studio.
3. Select Debug or Release (x64) and click **Build**.

SFML is downloaded automatically on the first build, so no manual setup is needed.
See [docs/setup.md](docs/setup.md) for configuration options and troubleshooting.

## Where tickets are stored

All tickets are stored in the repository **<https://github.com/DmitryV13/NMT>**:

- `tickets/`: one `.md` file per ticket, named by its ID. Each file holds the description, logs and a screenshot.
- `images/`: screenshots used in the tickets.
